# Akkusativ case

German marks the **direct object** of a sentence (the thing an action is done to) with
the accusative case. For most articles nothing changes — but the masculine article
shifts:

| Gender | Nominative (subject) | Akkusativ (direct object) |
|---|---|---|
| masculine | der / ein | den / einen |
| feminine | die / eine | die / eine (unchanged) |
| neuter | das / ein | das / ein (unchanged) |
| plural | die | die (unchanged) |

Example: "Der Mann sieht **den** Hund." (The man sees the dog.) `Der Hund` would be
wrong here because the dog is the object being seen, not the subject doing the seeing.

**How to identify the accusative object:** ask "wen?" (whom?) or "was?" (what?) about
the verb. "Der Mann sieht wen? — den Hund." That confirms `den Hund` is accusative.

**Common accusative prepositions** always take the accusative case regardless of
context: `durch` (through), `für` (for), `gegen` (against), `ohne` (without), `um`
(around). "Das ist für den Mann" (that's for the man) — `für` forces `den`, not `der`,
even though nothing is being "acted upon" in the usual sense.

Pronouns shift too: `er` (he) becomes `ihn` in the accusative — "Ich sehe ihn" (I see
him), not "Ich sehe er."
