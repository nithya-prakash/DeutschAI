# Tutor evaluation

40 questions (`apps/backend/evaluation/tutor_eval_set.json`, generated by `build_set.py`):
32 in-scope A1 grammar questions (2 for each of the 16 knowledge-base notes) and 8
out-of-scope ones (Genitiv, Konjunktiv II, passive, relative clauses, adjective endings,
Plusquamperfekt, plus two off-topic questions). The runner uses the app's own retrieval
(Qdrant + fastembed) and `build_tutor_graph`, and whichever LLM the environment configures.

```bash
# from apps/backend, with the image built from its Dockerfile
python -m evaluation.run_tutor_eval --label <name>      # Claude if ANTHROPIC_API_KEY is set
LLM_PROVIDER=openai LLM_BASE_URL=http://host.docker.internal:11434/v1 LLM_MODEL=qwen2.5:3b-instruct-q8_0 \
  python -m evaluation.run_tutor_eval --label ollama-qwen2.5-3b
```

## Metrics (all rule-based, no LLM judge)

| Metric | Definition |
|---|---|
| Retrieval hit@4 / hit@1 / MRR | the expected note is among the 4 retrieved chunks / ranked first / reciprocal rank |
| Correctness | every key fact for the question (regex groups written from the note) appears in the answer |
| Relevance | cosine similarity of question and answer embeddings (mean over all 40) |
| Groundedness | share of the answer's quoted or bolded German examples whose words all occur in the retrieved chunks |
| Out-of-scope flagged | answer says the topic is outside the notes (regex on the answer) |

## Results: local Ollama, qwen2.5:3b-instruct (q8), 2026-10-08

| Metric | Result |
|---|---|
| Retrieval hit@4 | **84%** (27 of 32); hit@1 59%; MRR 0.70 |
| Correctness | **53%** (17 of 32); 56% when the right note was retrieved |
| Relevance (mean cosine) | 0.64 |
| Groundedness (examples supported by context) | **56%** (31 answers with examples) |
| Out-of-scope questions flagged as outside the notes | **0 of 8** |
| In-scope answers wrongly flagged | 0 of 32 |
| Median latency | 11 s per answer (CPU, laptop) |

Raw answers: `apps/backend/evaluation/results/tutor_eval_ollama-qwen2.5-3b.json`.

## What this shows

- Retrieval is the strong part. The three-billion-parameter model is the weak part: it gets
  facts wrong (it calls Mädchen feminine, gives "der" for -ung nouns, writes 47 as
  "vierundsiebenzig") and answers all 8 out-of-scope questions confidently, including the
  Genitiv and passive, instead of saying the notes do not cover them.
- The correctness regexes are strict, so some correct answers count as misses (for example
  a right "den" answer that never uses the word "masculine"). Treat 53% as a lower bound,
  not an exact accuracy.
- Groundedness is a word-overlap proxy. It cannot tell a paraphrase from an invention.
